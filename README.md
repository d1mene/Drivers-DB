# Автопарк — GUI-клиент для БД PostgreSQL

Python 3.9+ · tkinter (встроен в Python) · psycopg2 · openpyxl

## Запуск в VS Code
1. `Файл → Открыть папку…` → выберите папку `autopark_app`.
2. Расширение **Python** (Microsoft) должно быть установлено. `Ctrl+Shift+P → Python: Select Interpreter`.
3. Терминал (`Ctrl+ё`):
   ```
   pip install -r requirements.txt
   ```
4. Откройте `config.ini` и впишите свои host / port / dbname / user / password (при необходимости — schema).
5. Один раз создайте пользователей (таблица `app_users` создаётся автоматически):
   ```
   python init_users.py
   ```
   По умолчанию: `admin / admin123` (все права) и `user / user123` (только просмотр).
6. Запуск: `python main.py` или `F5` (в проекте есть `.vscode/launch.json`).

## Как это соответствует заданию
| Требование | Где |
|---|---|
| а) файл параметров подключения | `config.ini` (читает `db.py`) |
| б) авторизация с хэшированием | `auth.py`: логин - SHA-256, пароль - PBKDF2-HMAC-SHA256 + соль; таблица `app_users` (2 пользователя, роли admin / user) |
| в) меню СПРАВОЧНИКИ / ЖУРНАЛЫ / ОТЧЕТЫ | `main.py` -> `build_menu()` |
| г) ввод, правка, просмотр | `record_form.py`, `grid_view.py` |
| д) GridView | `grid_view.py` (поиск, сортировка по клику на заголовок, двойной клик — открыть запись) |
| е) внешние ключи в гридах | `entities.py`: в «Автомобилях» — ФИО водителя, в «Журнале» — маршрут, номер авто, водитель, статус |
| ж) форма записи ДОБАВИТЬ / ИЗМЕНИТЬ / УДАЛИТЬ / ЗАКРЫТЬ | `record_form.py`, открывается из GridView |
| з) отчёты (2 шт., txt / xlsx) | `reports.py` |

## Отчёты
1. **Рекордное время проезда по маршруту** — вызывает вашу процедуру `get_fastest_trip`.
2. **Автомобили, находящиеся в рейсе** — вызывает вашу функцию `get_route_json_info`.

В обоих можно выбрать один маршрут или «Все маршруты». Результат показывается на экране и сохраняется в `.txt` или `.xlsx`.

## Заметки
* Роль `user` видит все данные, но кнопки изменения на формах заблокированы; роль `admin` может всё.
* Ошибки из ваших триггеров/ограничений (`RAISE EXCEPTION`, `CHECK`, FK) показываются пользователю в окне сообщения.
* В журнале есть кнопка **«Отметить прибытие»** — ставит время прибытия = сейчас.
* Ваш триггер на изменение маршрута создаёт копию старого маршрута, поэтому в списках могут появиться одинаковые названия — такие пункты помечаются `[#id]`.
* Приложение использует объекты, которые есть в вашей БД: таблицы `auto_personal`, `auto`, `routes`, `journal`, процедуру `get_fastest_trip`, функцию `get_route_json_info`.

## Структура
```
main.py         окно, меню, вход
db.py           подключение и запросы
auth.py         хэши и проверка пароля
init_users.py   создание пользователей
entities.py     описание таблиц/полей/гридов
grid_view.py    GridView
record_form.py  форма записи
reports.py      отчёты
config.ini      параметры БД
```
